# Zodex MC

A clean, simple launcher for Minecraft: Java Edition. It comes with our Fabric mods, resource packs and shaders already set up, so everyone plays with the same setup without copying files.

## Download
Grab the latest **ZodexMC-Setup.exe** from [Releases](https://github.com/Ziadod/Zodex-MC/releases/latest). After installing, Zodex MC updates itself.

## Features
- Sign in with your own Microsoft account (you must own Minecraft: Java Edition)
- Minecraft 26.2 with Fabric and a bundled set of performance and quality-of-life mods
- Bundled resource packs and shaders, set up automatically
- Add your own mods, resource packs and shaders from Modrinth
- Java is downloaded automatically, with an easy memory slider
- Automatic updates

## Sign-in and privacy
- You sign in on Microsoft's own login page. Zodex MC never sees your password.
- Your sign-in is stored encrypted on your PC and is only sent to Microsoft, Xbox Live and Minecraft services.
- Game files come from Mojang's official servers, and mods from Modrinth.
- No ads and no tracking.

## Requirements
- Windows 10 or 11 (64-bit)
- A Microsoft account that owns Minecraft: Java Edition
